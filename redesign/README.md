# сетка — redesign mockups

Статические мокапы нового интерфейса расписания ОмГУ. Ветка `develop/redesign`,
директория `redesign/`. Сборки нет: HTML + CSS + ванильный JS.

Существующий фронтенд `core/web/` не использовался и не менялся.

## Запуск

```bash
cd ~/opencode/projects/setka/core/redesign
python3 -m http.server 8099
# открыть http://127.0.0.1:8099/
```

Можно открыть `index.html` напрямую, но шрифты Google Fonts требуют сети.

## Экраны и маршруты

| Маршрут | Экран | Мобильный | Десктоп |
|---|---|---|---|
| `#/today` | Сегодня: день, «сейчас», оставшиеся пары | ✔ | — (десктоп открывает неделю) |
| `#/week` | Неделя | список по дням | сетка 6 дней × 8 пар + панель дня |
| `#/search` | Поиск по группам, преподавателям, аудиториям | полноэкранный | страница в основной области |
| `#/changes` | История изменений с diff «было → стало» | ✔ | ✔ |
| `#/settings` | Подписка: изменения, дайджест, напоминание, подгруппа, часовой пояс | ✔ | ✔ |
| `#/tutor` | Расписание преподавателя | ✔ | ✔ |
| `#/auditory` | Расписание аудитории | ✔ | ✔ |

Дефолт без хэша: на мобильном — «Сегодня», на десктопе — «Неделя».
Разметка для мобильного и десктопа рендерится в два корня
(`#mobile-app`, `#desktop-app`), показ переключает медиазапрос на 980 px.
Мобильный вид — приоритетный: все экраны сначала собраны под 390×844.

## Темы

Тема переключается в «Настройках»: **Светлая / Тёмная / Системная**. Выбор
хранится в `localStorage` (`setka-theme`), применяется до первой отрисовки
(инлайн-скрипт в `<head>`), поэтому нет вспышки светлой темы. «Системная»
следит за `prefers-color-scheme` и реагирует на смену настроек ОС без
перезагрузки. `theme-color` браузера обновляется вместе с темой.

Тёмная тема — не инверсия: бумага становится глубоким зеленоватым графитом,
«табло» и сайдбар остаются тёмными, акцентный красный светлеет, а выбранный
день и кнопки становятся светлыми «бумажными» пятнами. Токены — в
`DESIGN.md`.

## Иконки и манифест

- `assets/favicon.svg` — знак «с» + красный квадрат, тот же язык, что у
  wordmark «сетка»;
- `assets/favicon-32.png`, `assets/apple-touch-icon.png` (180),
  `assets/icon-192.png`, `assets/icon-512.png`;
- `assets/og.png` — карточка 1200×630 для соцсетей;
- `site.webmanifest` — PWA-манифест (standalone, ru, theme/background).

Иконки отрендерены из `assets/icon.html` и `assets/og.html` (HTML → PNG),
поэтому их можно пересобрать без графического редактора.

## Подгруппы

Подгруппы определяются из расписания (поле `subgroupName`, значения `1`, `2`).
Выбор живёт в «Настройках → Расписание → Моя подгруппа» и в `localStorage`
(`setka-subgroup`). Он влияет на всё:

- день, неделя и десктопная сетка показывают занятия выбранной подгруппы и
  общие занятия без подгруппы;
- слот, где у подгрупп разные пары, после выбора становится одной парой, а в
  режиме «Все» остаётся объединённым слотом с подробностями в шторке;
- если у выбранной подгруппы занятий нет, показывается пустое состояние и
  кнопка «Показать все»;
- в шапке появляется «группа · подгруппа 1» со ссылкой в настройки, на десктопе
  подгруппа выводится в подзаголовке;
- поле `subgroup` в настройках уведомлений использует то же значение.

## Группы

Выбранная группа хранится в `localStorage` (`setka-group`), настройки
уведомлений — в `setka-notify`. Переключение —
из результатов поиска и из списка «Мои группы» на десктопе; у каждой демо-группы
свой вариант расписания. Смена группы сбрасывает неделю и выбранный день, но
сохраняет подгруппу и тему.

## Данные

Все занятия, преподаватели, оценки и изменения — **синтетические**, но в реальных
форматах API: группы `ЮСС-003-О-02`, `ЮСС-002-О-01`, `ЮСС-001-О-03`,
`МЕН-004-О-02`, аудитории `1-102`, `4-308`, пары 1–8, дни `DD.MM.YYYY`.
У групп разные варианты расписания, чтобы переключение было заметно. Настоящие контракты и ограничения — в
`../dev/API_DATA.md`.

## Что работает в мокапе

- слоты: занятия одной пары объединяются в одну строку (мобильный) или ячейку
  (десктоп). Как и в текущем фронтенде (`web/src/components/ScheduleContent.tsx`),
  объединяются записи с одинаковыми предметом, типом, преподавателем и
  аудиторией; разные аудитории и преподаватели остаются отдельными занятиями
  внутри слота;
- слот с несколькими занятиями показывает количество, названия и аудитории,
  а подробности открываются в шторке снизу;
- клик по одной паре тоже открывает шторку: ФИО преподавателя, аудитория и
  корпус, группа, подгруппа, замена, ссылки на расписание преподавателя и
  аудиторию; у текущей пары для этого есть кнопка «Детали» в полосе «сейчас»;
- переключение групп из поиска и списка «Мои группы» (выбор запоминается);
- переключение дней в полосе дней (для «не сегодня» показывается сводка дня);
- переключение недели вперёд/назад (вторая неделя без части занятий);
- поиск от 2 символов, группировка результатов, очистка, недавние запросы;
- фильтр изменений «Моя группа / Все группы»;
- настройки: переключатели, зависимые поля (время дайджеста, минуты напоминания),
  автосохранение с подтверждением, двухшаговая отписка;
- переходы в карточки преподавателя и аудитории;
- из записи изменения можно открыть пару в шторке;
- офлайн-баннер по событию `offline`;
- видимый фокус, семантика кнопок/ссылок, `aria-pressed`, `aria-current`,
  `role="status"`, `prefers-reduced-motion`.

## API и план фронтенда

- `API_READINESS.md` — что API уже умеет, где блокеры и какие доработки нужны;
- `FRONTEND_PLAN.md` — план нового фронтенда по мокапам, этапы и интеграция;
- `COVERAGE.md` — матрица «мокап → API → статус». Кратко: не входят

групп в избранное.

## Чего нет

- реальных запросов к `/api/v1` — данные в `app.js`;
- авторизации, PWA-манифеста, service worker, FCM;
- iCal и админки — сознательно вне студенческого флоу;
- роутера с историей: только hash-маршруты без вложенности.

## Дизайн

Направление: **печатный бланк расписания + живое табло**. Структура листа
(линейки, крупные номера пар, жёсткая сетка) отвечает за чтение, тёмная полоса
«сейчас» и красные метки — за состояние. Подробности и токены — в
`DESIGN.md`.

Шрифты: Oswald (номера, слово, заголовки-акценты) + Golos Text (интерфейс).
Палитра: холодная бумага `#E9EAE3`, чернила `#151A14`, сигнальный красный
`#C22C12`, поверхность `#F7F8F3`.

## Файлы

- `index.html` — точка входа, два корня приложения, тема до первой отрисовки;
- `style.css` — светлые и тёмные токены, мобильная вёрстка, десктоп от 980 px;
- `app.js` — демо-данные, рендер, темы, обработчики;
- `assets/` — favicon, touch/PWA-иконки, OG-карточка и их HTML-исходники;
- `site.webmanifest` — манифест;
- `PRODUCT.md` — продуктовая правда;
- `DESIGN.md` — токены и правила визуальной системы.
